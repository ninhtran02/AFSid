# AFSid

R code accompanying the paper *Uniformly improved adaptive filtering procedures for replicability testing with FWER control* by Ninh Tran.

## Contents

This repository contains R scripts for reproducing the simulation studies and real-data analysis presented in the paper.

## Requirements

R and the packages specified in the scripts.

## Data

The real-data analysis uses the publicly available GEO dataset GSE30495 (https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE30495).
